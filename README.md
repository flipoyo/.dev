How GX4G's work gets done: the before-committing checklist with GX4G's own
commands ([gx4g-dev.md](gx4g-dev.md)), how it numbers and releases
([Versioning.md](Versioning.md)), the architecture and the Rust ideas under it in
diagrams ([RustGuide.md](RustGuide.md)), and the planning surface

This branch, `gx4g`, is GX4G's own, private and writable, unlike
`dev-sync` (`DevSpec`), which is shared, read-only, and the same for every
project. Each document here fills in a shared pattern and opens with a
`*Fills in:*` line naming it; the shared one holds the rule.
